How the columns are read

Only Name is required — everything else is optional and matched by its heading, so most supplier sheets import as-is without editing. Headings are case-insensitive.

Matching: an item is updated if its Code matches an existing item, or failing that its Name matches exactly. Otherwise it's added as a new item.
