📦 Bulk import a whole folder

Select every .DBF file at once — a year's worth of exports, ITEM.DBF plus every monthly ITEMTRAN.DBF, whatever you've got. Each file's type and column mapping are auto-detected and imported with no per-file review. Fields the auto-mapping doesn't recognise are never thrown away — every column from the file is kept and will be viewable/editable once you turn on the customization view (coming next).

ℹ️ Use the single-file wizard above instead when you want to check the field mapping before it runs — bulk mode trusts the auto-detection completely.

⚠️ Clear previous data

Deletes all medicines and all bills currently in the system — the placeholder/legacy-import data you no longer need, so this software can be the one real billing system going forward. Does not touch staff logins, settings, or licensing. This cannot be undone.
