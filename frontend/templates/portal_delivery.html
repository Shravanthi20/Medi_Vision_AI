Enable Google Maps

  1. Go to console.cloud.google.com
  2. Enable Maps JavaScript API & Directions API
  3. Create an API key
  4. Add to START_APP.bat: SET GOOGLE_MAPS_KEY=your_key_here
  5. Restart the server — map will appear here automatically
